# FanyiX

FanyiX 是一款 macOS 选中文字翻译工具。在网页、聊天或文档中选中文字，按下快捷键，即可通过 AI Agent 进行中英文互译。可编辑的选区自动替换，只读文字在翻译历史中查看和复制。

## 安装

当前安装包适用于 **Apple 芯片（M 系列）Mac，macOS 13 及以上**。使用前，请先在电脑上安装并登录 **Codex、Claude、Pi 中的任意一个命令行工具**，确认它可以正常使用。

1. [下载 FanyiX.zip](https://github.com/bravf/fanyix/raw/refs/heads/main/dist/FanyiX.zip)，解压得到 `FanyiX.app`。
2. 将 `FanyiX.app` 拖到「应用程序」，从 Finder 双击打开，菜单栏会出现 **F 图标**。
3. 在「系统设置 → 隐私与安全性 → 辅助功能」中允许 **FanyiX**。如果列表中没有，点击 `+` 添加「应用程序」中的 FanyiX。
4. 点击菜单栏 **F 图标 → 设置 → Agent 与模型**，选择要使用的 Agent 和模型。应用会自动查找本机已安装的 Agent。

## 使用

1. 在需要翻译的应用中选中文字。
2. 按 **⌘⌥E（Command + Option + E）**，开始翻译。
3. 中文自动译为英文，英文自动译为中文；中英混合时按主要语言判断。

- **输入框等可编辑文字**：翻译完成后自动替换选区，不会自动发送消息。如果翻译期间修改文字或改变选区，结果会保留供复制。
- **网页正文等只读文字**：自动打开翻译历史，展示本次原文和译文。
- **没有选中文字**：按同一快捷键直接打开翻译历史。历史仅在本机保留最近 **100 条**，可逐条删除或清空。

在「设置 → 翻译」中可选择三种替换方式：**仅译文**、**原文 [译文]**、**译文 [原文]**。同一页还可以开启 **英文注释**（默认关闭）：开启后，Agent 会额外用中文解释英文单词、固定搭配和语法。原文是英文时解释原文中的英文，原文是中文时解释英文译文中的英文；替换到输入框的仍然只有译文，注释只保存在翻译历史的详情中。注释会增加少量翻译耗时与 token 消耗。

在「设置 → 快捷键」中可更换翻译快捷键。

翻译时会显示简洁浮层，可以拖动调整位置，或展开查看历史详情。菜单栏 F 图标下可打开「翻译历史」「设置」或退出应用。

如果授权后仍显示待授权，先退出并重新打开 FanyiX；仍未恢复时，在辅助功能列表中移除旧条目，再添加当前安装的应用。
